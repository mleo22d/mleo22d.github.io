# Portafolio – Matías Loayza Correa

Sitio publicado en: https://mleo22d.github.io

## Cómo actualizarlo
- **Fotos:** súbelas a `images/` con los nombres que aparecen en cada tarjeta (por ejemplo `images/robot-arm.jpg`). Recomendado: 1600×1000 px, JPG de menos de 400 KB.
- **Proyectos, enlaces a código y videos:** edita la lista `PROJECTS` al final de `index.html` (campos `repo`, `video`, `image`).
- **CV:** reemplaza `cv/CV_Matias_Loayza.pdf`.
